# 🏛️ 動態陽宅與方位 (Dynamic Feng Shui & Directions Visualizer)

後天派陽宅分金、立太極、三元九運水法與禁水路動態平面圖互動可視化系統。

---

## 🌟 系統核心特色 (Key Features)

1. **🏠 房屋長寬與格局動態對照 (Dynamic Floorplan Scaling)**：
   - 支援自由調整房屋面寬 (W) 與進深 (L) 尺寸（以實際比例 m 呈現）。
   - 自動分割 **四象限 (前左/前右/後左/後右)** 實體房間分區，動態運算各分區落入之八卦、九星星曜與親人安床建議。

2. **🧭 二十四山與後天派分金判定 (24 Mountains & Fen-Jin)**：
   - 即時計算坐山與向山角度（以 `辰山戌向 307.0°` 為基礎範例）。
   - 動態檢測 **307.5° 戌乾陰陽分界空亡線**，當角度接近 1° 範圍內時自動觸發空亡警示，並提供 5 大專業化煞解法。

3. **🚪 動態大門立極與門向偏角調整 (Door Ingress & Angle Offset)**：
   - 支援在 **前牆、右牆、後牆、左牆** 自由切換開門位置與比例 (%)。
   - 提供大門朝向偏角微調 (-45° ~ +45°)，可動態模擬「偏角門工法」，精確計算大門氣口引導之九星氣場。

4. **🌐 三元九運全九運 (一運 ~ 九運) 羅盤動態連動**：
   - **九運 (2024~2043)**：正南離為正神（宜靠山）、正北坎為零神（水藍色光環 💧 最宜見水/放水溝大聚財）。
   - **一運 ~ 八運**：切換任一元運，羅盤與平面圖即時高亮當前元運之 **零神吉水位** 與 **正神靠山位**。
   - 支援將滑鼠移至元運選單上 **滾動滾輪 (Scroll Up/Down)** 快速輪播全九運！

5. **🍊 艮位專屬水路警告與衛廁廚房分工 (Gen Sector Water Rules)**：
   - 高亮標示 **東北艮卦 (22.5°~67.5°)** 橘橙色警示。
   - 獨家解析：艮位忌明溝走水流走（沖散山氣財庫），但室內衛廁暗管可作壓煞化權。

6. **🛏️ 全家親人 (父母 / 長男 / 長女) 最佳安睡指南**：
   - 依據後天派「吉星飛臨位為最高準則」，動態計算父母、長男、長女的最佳安床方位與卦位對照。

7. **🧱 陽宅格局規劃器 (Floor Planner Tool)**：
   - 內建互動式 SVG 格局畫板，支援點擊放樣與直接拖曳繪製各功能房間（客廳、臥室、廚房、衛浴、書房、陽台等）與陽宅關鍵設施（安睡床位、壓煞灶位、文昌書桌、排污馬桶、氣口門路）。
   - 提供 **0.5m 網格吸附 (Grid Snap)**、**九宮八卦對角線即時套疊**、**建物面積 (m²) 與坪數自動合算**，以及 **八卦九宮落入動態理氣診斷**。
   - 支援 1 鍵套用至陽宅羅盤、JSON 儲存與載入，並內建 2房/3房等標準格局範本！

## 🛠️ 技術架構 (Technology Stack)

- **前端核心**：Vanilla HTML5 / SVG / JavaScript (ES6+)
- ** UI 設計語彙**：Windows 11 Dark Mode Mica 視覺風格，細字體高質感配色
- **無外部重型框架**：全單一檔案零依賴 (Zero Dependency)，載入極速
